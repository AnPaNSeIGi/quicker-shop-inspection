# 跨境电商店铺自动巡检系统（Quicker 动作）

> 使用 **Quicker** 桌面自动化工具实现的"无人店铺"日常巡检流水线。
> 针对日本电商平台（乐天 RMS / XServer / Wowma 等）多店铺批量运营场景，
> 通过图像识别 + 键盘鼠标模拟 + Excel 数据驱动，实现店铺登录、后台巡检、
> 异常捕捉、截图留档的全流程自动化。

---

## 一、项目背景与价值

在跨境电商（日本乐天/雅虎等平台）多店铺代运营业务中，运营人员每天需要
逐店登录后台检查商品、库存、邮件、登录状态等。店铺数量多、平台登录限制
频繁（人机验证、二次验证、密码过期提示），人工巡检耗时且易漏。

本项目用 **Quicker 动作** 将整套巡检流程脚本化：

- ✅ **数据驱动**：巡检哪家店铺、用哪组账号密码，全部由 Excel 表格驱动，新增店铺只需加一行数据
- ✅ **图像识别定位**：不依赖固定坐标，通过位图匹配（searchBmp）识别按钮/界面元素，适配界面变动
- ✅ **异常自适应**：内置人机验证检测、登录失败检测、广告弹窗跳过、改密码提示识别等多分支逻辑
- ✅ **全程留痕**：每次巡检自动截图（RMS 后台 / 邮件界面）并按时间戳命名归档，可追溯可复盘
- ✅ **无人值守**：配合 Windows 计划任务 + BIOS 定时开机，可实现夜间自动巡检

## 四、快速开始

### 1. 准备环境
- Windows 10/11 + [Quicker](https://getquicker.net/)
- [紫鸟浏览器](https://www.ziniao.com/)（跨境电商指纹浏览器）
- Python 3.8+（可选，仅运行辅助脚本时需要）

### 2. 还原路径
仓库中动作文件的资源路径已替换为占位符（`{{QUICKER_ROOT}}` / `{{ZINIAO_EXE}}`），
在你本机导入前需先还原：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\restore_paths.ps1
```

按提示输入你的资源根目录（包含 `组件库\quicker位图`、`RMS记录` 等子目录的文件夹）
和紫鸟浏览器路径即可，脚本会自动生成可用的 `查看店铺巡检动作_本机路径版.json`。

### 3. 准备数据表
将 `data\无人店铺操作表格_示例.xlsx` 替换为你自己的店铺数据表
（保持列结构一致：店铺名 / R-Login ID / 登录密码 / 用户ID / 邮箱等）。

### 4. 导入并运行
在 Quicker 中导入还原后的 JSON 动作文件，配置好触发器（快捷键/定时）即可运行。

## 五、核心实现要点

### 5.1 图像识别定位（不依赖固定坐标）
所有关键按钮、输入框、状态图标均通过 `searchBmp` 位图匹配定位，
配合 `searchRect` 限定搜索区域、`bmpColorError` 颜色容差，
即使窗口位置/分辨率变化也能正确定位。

### 5.2 多分支异常处理
- **人机验证**：识别验证码图标 → 等待人工/自动通过 → 超时重试
- **登录失败**：识别失败提示 → 截图留档 → 标记该店铺
- **广告弹窗**：识别并点击关闭按钮 → 跳过
- **改密码提示**：识别"需改密码"图标 → 记录到"需改密码栏目"

### 5.3 Excel 数据驱动
巡检循环以 Excel 行为单位：读取店铺账号 → 执行巡检 → 下一行。
新增/删除店铺只需维护表格，无需改动脚本逻辑。

### 5.4 截图留档
每次巡检自动将截图保存至两处独立目录（对应脚本中的硬编码输出路径）：
- **RMS记录/**：RMS 后台巡检界面截图（`rms_yyyyMMddHHmmssfff.png`）
- **邮件记录/**：邮件登录检查截图（`mail_yyyyMMddHHmmssfff.png`）

两处截图分别留档，配合 `文件内图片命名.py` 可按时间顺序统一归档。
